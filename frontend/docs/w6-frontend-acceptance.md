# 第六周成员 B 前端交接与验收记录

日期：2026 年 11 月 1 日。基于原 Vue 工程增量实现。本文分别记录本地自测、本客户端真实接口结果和仍待独立验收的事项，不把纲领中的后端交接说明视为全组验收结论。

## 契约和实现范围

新增接口严格采用 `project/docs/w6-api-contract.openapi.json` 0.6.0，与桌面原文件 SHA256 相同：`7C2DBA67D8B430AFB24FDD4F8F69BC49E20738713E41F64DC7BC373FB1D0100A`。原状态 `RULES_FIXED_PENDING_IMPLEMENTATION` 保留；实际服务可用性在下文单独记录。

- 省级 `/province/analysis`：各市企业数/占比表与饼图；两期六项指标表，可选指标切换柱状/折线；连续多期岗位变化占比折线与同值六指标表。
- 调查期从既有省级接口读取，排除 legacy 旧版只读期次。趋势按 `startAt`、`code` 升序，选择起止后自动包含中间全部期次，2–24 期；不是按自然月推测相邻。
- 城市视图支持地区子树；对比/趋势还支持性质、行业父子代码。清除样本条件后重新查询，保留已选期次。结果注明响应实际条件，修改条件需重新查询。
- 表图共用响应数据，前端不重新计算正式指标；百分比直接格式化为两位小数，不重复乘 100。负数柱在零线下方，null 显示“—”并断线，空期保留，零样本不绘制饼图。
- 三类备案来源计数单列展示；省级修订/作废后刷新分析，使用当前有效值。Mock 复用 W5 同一内存样本，不覆盖原快照与事件。
- 省级 `/province/notices` 支持分页、发布、详情、整份修改、逻辑删除确认；企业/市级各自 `/notices` 页面仅浏览所属省通知。页码 API 从 0 开始、界面从 1 开始，删除末页最后一项后回退有效页。
- 通知标题和正文 trim 后按 Unicode 码点分别限制 1–50/1–2000 字，含 emoji 边界；纯文本保留换行。发布人、单位、发布时间不从表单提交，修改保留原发布身份和时间。PUT 带 `expectedVersion`，DELETE 通过查询参数传版本；409 不自动覆盖，独立刷新详情和列表，404 清除失效详情。
- 用户、角色、系统监控及部委上报继续占位。未增加未经契约约定的省级字典、通知审计查询或分析导出接口。

## 六项指标与本地手算样例

样本：本省 `APPROVED_PROVINCE` 且未作废、每企业同期最新提交版本；人数取当前有效修订值。性质/行业按提交关联备案版本优先，缺失回退当前资料，再缺失标记不可用。每期独立取样，不取两期企业交集，也不使用账号查询样本。

| 指标 | 公式与空值规则 |
| --- | --- |
| 企业总数（家） | 合格样本中去重企业数 |
| 建档期总岗位（人） | 建档人数之和 |
| 调查期总岗位（人） | 有效调查人数之和 |
| 岗位净变化（人） | 调查期合计 − 建档期合计，允许负数 |
| 岗位减少总数（人） | 逐企业 `max(建档人数−调查人数,0)` 累加，不被增员抵消 |
| 岗位变化占比（%） | 净变化 ÷ 建档期合计 × 100，HALF_UP 两位；无样本或分母零为 null |

本地可复现数据在 `tests/week6-analysis.spec.ts`，为匿名内存样本，不是共享数据库数据；此表是 B 的测试期望，不能替代 C 的独立手算/SQL 复核。

| 步骤/期次 | 企业数 | 建档 | 现值 | 净变化 | 减少总数 | 变化占比 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| A：甲市 100→80、乙市 50→60 | 2 | 150 | 140 | −10 | 20 | −6.67% |
| B：另一企业 200→220，独立样本 | 1 | 200 | 220 | +20 | 0 | 10.00% |
| C：无样本 | 0 | 0 | 0 | 0 | 0 | — |
| A：甲市现值修订为 70 后刷新 | 2 | 150 | 130 | −20 | 30 | −13.33% |
| A：再作废乙市报表后刷新 | 1 | 100 | 70 | −30 | 30 | −30.00% |

A 两市各 1 家，分母 2 家，各 50.00%；缩到乙市后分母 1 家，占比 100.00%。A 备案来源为冻结版本 1、当前回退 1；另测 C 存在一条 0→0 且资料不可用的报表，企业数 1、来源不可用 1、变化占比仍 null。测试同时验证修订后原提交快照不变、当前备案修改不污染冻结资料筛选。
