## 真实只读接口

省级调查期、企业期次、原因字典、报表读取和历史列表返回 200，字段符合契约；市级访问省级期次返回 403。字典返回 10 类减少类型、16 组原因，数量不代表已完成老师原始字典逐项复核。

最新版契约状态为 `LOCAL_IMPLEMENTED_PENDING_SERVER_DEPLOYMENT`，表示后端本机已实现验证、尚待服务器部署。此次更新仅涉及说明和交付状态，版本号、接口路径、字段、校验和业务规则均未变化，前端代码无需调整。此前服务器只读探测可用不代表新版完整服务已部署；服务器当时仅返回 DEMO_2026_10，窗口 UNAVAILABLE、canWrite=false。本次未新增真实调查期或报表，真实写入、截止瞬间边界和共享环境浏览器完整闭环待同版部署后验证。

## Mock 演示

运行 `npm run dev:mock`，使用 README 演示账号。先完成第二周企业备案并由省级通过，同一页面退出重登保留内存数据；刷新重置。

省级预置开放和未开放两个 Mock 期次；可新增期次并修改未开放期次。企业在开放期保存，退出重登后读取，人数减少时漏原因应阻止提交，补齐后进入 SUBMITTED_CITY。历史展示提交快照，下期带锁定基准。Mock 字典仅为明确标记的精简样例，正式完整字典来自后端。
