# 第五周成员 B 前端交接与验收记录

日期：2026 年 11 月 1 日。前端在既有工程增量开发，新增接口严格遵循 `project/docs/w5-api-contract.openapi.json` 0.5.0，文件与用户提供版本一致。契约状态仍为 `RULES_FIXED_PENDING_IMPLEMENTATION`，不修改为已部署。

## 已实现范围

- 省级“数据汇总” `/province/summary`：调查期、地区子树筛选；本省已省审通过且未作废的最新提交版本，展示企业数、建档/调查人数合计、净变化及各市基础汇总。有效报表、报送期企业信息分别分页预览。
- 两类报送期 Excel 与预览共用已应用的期次和地区条件；导出全部匹配行，不附加分页参数。旧版第二周备案导出保持原口径。
- `/province/data/reports/:reportId`：原始值与当前有效值逐字段比较；九个可修订字段，建档期人数只读；修订原因必填，完整有效表单的条件必填、非负整数、原因与说明配对校验；差量提交，空字符串转换 null；版本双校验、409 重新读取、404 清除详情。
- 修订日志展示操作 ID、提交版本、原值、新值、原因、操作人员和北京时间。作废原因必填、二次确认，无恢复操作；已作废报表从普通结果排除，仍可按 ID 追溯。
- 省级审核完成详情链接到修订页；企业历史追加作废标记与时间，保持只读，原始提交快照保留。
- `/province/accounts`：单位名、账号、三角色、地市/县区/区域、备案状态、性质/行业代码、创建日期、调查期、月份、季度和报表状态组合查询。地区取现有接口，支持选择地区子树；地市与县区限制相应级别。清除删除全部筛选并重新请求 API 第 0 页。界面使用 1 基分页。
- 账号导出使用当前列表已应用条件，编辑但未查询的条件不会改变导出范围。无结果提供空态，下载 JSON 错误不会伪装为 XLSX。
- Mock 接续既有填报、市审、省审内存数据，修订与作废不覆盖原快照和审核事件。无默认伪造的省审通过样本，刷新重置。

## 已冻结业务口径

修订和作废保持 `APPROVED_PROVINCE` 状态，不增加提交版本或审核事件，只递增当前版本。建档人数和企业基准不改。九字段以契约 `CorrectionChanges` 为准（纲领概述的字段数量不替代契约清单）。原值来自最新提交快照，有效值叠加修订。

汇总/有效数据/两类报送期 Excel 只使用省审通过、未作废样本；净变化为调查人数减建档人数。企业信息显式展示 `SNAPSHOT_VERSION`、`CURRENT_FALLBACK` 或 `UNAVAILABLE`，不得将回退资料宣称为历史冻结版本。

账号 `dataStatus` 是当前企业备案状态。日期是北京时间账号创建日；月份/季度按调查期 `startAt` 北京时间计算，期次条件要求企业有该期报表，含草稿，普通查询排除作废报表的关联。`reportStatus` 必须同时指定调查期。样本范围与汇总不同。

## 真实只读探测与接口缺口

2026-11-01 从本客户端直连（Node fetch，未使用系统代理），健康检查 200，既有省级演示登录 200，省级期次列表 200。以下第五周端点只读探测均返回 404：

- `GET /province/accounts?page=0&size=1`
- `GET /province/summaries?periodCode=<既有期次>`
- `GET /province/data/reports?page=0&size=1&periodCode=<既有期次>`

本次仅登录和读取，不创建账号、期次或报表，不修订、作废或审核共享数据。未对未部署接口作真实验收结论。

**省级字典缺口**：既有 `/enterprise/reports/options` 与 `/enterprise/filing/options` 使用省级 Token 均返回 403，W5 未新增省级字典能力。因此前端不发这两条无权请求，不猜测新路径、不硬编码字典。修订页保留响应代码并支持输入代码，由服务端完成完整字典/层级校验；账号性质与行业暂按代码筛选，结果展示代码和名称。前端仍校验人数、必填、长度和说明配对。A 应补充省级可读字典契约或明确扩展现有权限，之后可切换字典选择器；这是完整交互验收的待办。

## 演示步骤

在 `project/frontend` 执行 `npm run dev:mock`，省级 Mock 账号见 README。账号查询和零汇总可直接演示；有数据修订需先完成企业备案、企业提交、市审通过、省审通过，再进入“数据汇总”选择该期次，从有效报表点击“修订 / 追溯”。修订后返回汇总重新查询，再作废并核对普通结果排除。作废前记下报表 ID，可在汇总页底部按 ID 追溯。

同一页面退出切换角色可保留 Mock 数据；刷新将清空。真实联调使用 `npm run dev`，当前 W5 404 需等待后端部署。
