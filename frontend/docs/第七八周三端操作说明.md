# 第七、八周三端操作说明

2026-11-14，接口基线为 [第七八周 OpenAPI](../../docs/第七八周前后端接口约定.openapi.json)，版本 `week7-8-contract-2026-11-14`。

## 登录与权限

使用组内分配的账号登录。页面按当前身份和有效权限显示导航与操作。当前账号的权限发生变更时，服务端按最新权限校验请求。遇到 403 可返回工作台，或退出后切换账号。重置密码、停用或删除导致会话失效时，需要重新登录。

本地从 `project/frontend` 运行 `npm run dev:mock`，选择相应演示身份。共享环境通过真实模式联调。本地监控显示未采集，所有截图使用本地匿名数据。

## 省级端

1. 在「用户管理」按用户名或显示姓名、所属组织、身份、状态筛选。查看详情可核对账号的创建时间、角色和有效权限。创建账号时搜索已有组织，指定初始密码和至少一个同级功能角色。要创建新企业组织，使用「创建企业账号」。
2. 在账号详情选择修改姓名和角色、启用或停用、重置密码、删除。提交前核对用户名与组织。存在报表提交或审核记录的账号可停用。系统会检查最后一个具完整管理权限的省级管理员。遇到版本冲突，关闭操作窗口，重新打开详情并核对后再提交。
3. 在「角色与权限」按层级查看权限及使用人数。创建角色时选择层级和本级功能权限。删除已分配角色时选择同级替代角色，核对影响人数后确认。详情中的已分配账号列表还需用户查看权限。
4. 打开「系统监控」查看主机资源和依赖探测。页面每 30 秒刷新，也可点击「刷新监控」。查看单项状态和最近检查时间，刷新失败时可核对上次采样时间。
5. 日常业务从企业备案、调查期管理和省级报表审核进入。按调查期查看汇总、图表或立方体。检查国家上报门槛，按授权生成代填、冻结 XML，打开批次详情核对分片及模拟回执。

## 市级端

登录查看本市填报进度与审核队列。在「辖区报表审核」按期次和状态查询，打开详情查看当前提交快照及审核时间线。按授权通过或退回，退回可填写备注。通过后进入待省审。可在「通知管理」查看通知，按授权发布或维护本市通知。

[市级工作概览](screenshots/week78-city-home.png)

## 企业端

打开「企业基本信息」填写并保存备案，确认资料后提交，在「备案状态」查看结果及退回原因。备案通过后进入「数据填报」，选取期次并核对建档来源，填写调查期人数及原因。按授权保存草稿、提交或从「待上报报表」批量提交。退回后可在历史记录查看意见，按权限修改并重报。通知从「通知浏览」查看。

## 联调记录

- 本地 61 项自动测试通过。Mock 浏览器验证了三端登录、省级图表与多维分析、国家上报入口，以及用户创建、账号停用、角色替代删除、监控空值、受限菜单和直接访问 403。账号、角色和监控页面已截取实际运行画面。

- 用户、角色、监控和权限显示以第七八周契约为基线。无 `permissions` 字段的旧版 `/auth/me` 继续开放旧入口，新管理入口须由新版响应授权。
- 账号编辑和建号选取角色需要角色查看权限。角色详情读取分配账号需要用户查看权限。没有调查期查看权限时，支持在依赖该目录的查询中直接输入适用的期次代码。连续趋势与日历汇总依赖完整调查期目录。
- 共享环境健康检查 HTTP 200，匿名访问监控 HTTP 401。联调说明中的旧演示账号三类登录均返回 HTTP 401。受保护接口、权限矩阵及真实依赖监控需用同版服务和有效账号复验。共享环境业务链、服务故障演练、恢复核对和三方签收仍待对应环境及证据。
