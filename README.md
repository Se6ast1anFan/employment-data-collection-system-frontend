# 企业就业失业数据采集系统

本仓库用于“卓越工程综合训练”三人团队项目。

## 目录说明

- `project/frontend`：Vue 3、TypeScript、Vite、Element Plus、Vue Router、Pinia 前端工程。

## 启动前端

```powershell
cd project/frontend
npm ci
npm run dev
```

浏览器打开 `http://127.0.0.1:5173/`。真实演示账号和密码不保存在仓库中，请使用团队内部的第一周前端联调说明。

后端暂时不可用时，可以运行：

```powershell
npm run dev:mock
```

详细说明见 `project/frontend/README.md`，联调结果见 `project/frontend/docs/w1-frontend-acceptance.md`。
